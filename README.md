# CxArot - 教学评价

本项目是为 **重庆电子科技职业大学(CQUET/CQCET)** 的学生设计的一款教学评价自动化脚本。旨在帮助同学们快速完成期末对教师的教学评价任务，将更多时间用于学习和复习。

提供了 **Python** 和 **Go** 两个版本，功能一致，可根据个人喜好选择使用。

## ✨ 主要功能

*   **多用户并发**：支持配置多个账号，脚本使用多线程/协程并发执行，适合宿舍或多人同时使用。
*   **自动登录**：配置学号/手机号和密码后，脚本可自动完成登录过程。
*   **智能识别**：自动获取当前学期所有需要进行教学评价的课程和教师列表。
*   **一键评价**：自动为所有待评价的教师提交评价（默认高分），快速完成任务。
*   **日志记录**：运行过程详细记录，便于查看评价状态。

## 🛠️ 环境要求

### Python 版本
*   Python 3.12+
*   [uv](https://github.com/astral-sh/uv) (推荐用于依赖管理)

### Go 版本
*   Go 1.20+ (仅编译需要，直接运行无需环境)

## 🚀 使用说明 (Python 版本)

### 1. 克隆或下载项目

```bash
git clone https://github.com/Sen0E/CxArot.git
cd CxArot
```

### 2. 安装依赖

本项目推荐使用 `uv` 进行依赖管理。

```bash
# 如果未安装 uv
pip install uv

# 同步项目依赖
uv sync
```

如果不使用 `uv`，也可以手动安装依赖：
```bash
pip install requests lxml loguru
```

### 3. 配置信息

打开 `main.py`，找到 `users` 字典配置区域，填入你的账号（手机号或学号）和密码。支持同时配置多个账号。

```python
if __name__ == '__main__':
    # 格式：{"账号": "密码", "账号2": "密码2"}
    users = {
        "13800000000": "YourPassword",
        "20230001": "AnotherPassword"
    } 
    # ...
```

> **安全提示**：直接在代码中存储明文密码存在风险，请确保该文件不会被泄露给他人。

### 4. 运行脚本

使用 `uv` 运行（推荐）：

```bash
uv run main.py
```

或者直接使用 Python 运行（需确保依赖已安装）：

```bash
python main.py
```

脚本将开始执行，控制台会输出简要信息，详细日志请查看生成的 `AROT.log` 文件。

## 🐹 使用说明 (Go 版本)

Go 版本位于 `cx-arot` 目录下，提供了单文件执行和交互式输入体验。

### 1. 进入目录

```bash
cd cx-arot
```

### 2. 运行脚本

如果你已安装 Go 环境，可以直接运行：

```bash
go run main.go
```

或者编译成可执行文件后运行（适合分发给没有 Go 环境的同学）：

```bash
# 编译
go build -o cx-arot main.go

# 运行 (Windows)
./cx-arot.exe

# 运行 (Linux/Mac)
./cx-arot
```

### 3. 交互式输入

Go 版本采用交互式命令行界面：
1.  程序启动后，会提示输入 **手机号**。
2.  接着提示输入 **密码**。
3.  程序将自动登录并开始评教，实时输出进度。
