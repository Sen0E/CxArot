# CxArot - 教学评价脚本

本项目是为 **重庆电子科技职业大学(CQUET/CQCET)** 的学生设计的一款教学评价自动化脚本。旨在帮助同学们快速完成期末对教师的教学评价任务，将更多时间用于学习和复习。

## 主要功能

* **自动登录**：配置学号和密码后，脚本可自动完成登录过程。
* **获取待评任务**：自动获取所有需要进行教学评价的课程和教师列表。
* **一键满分评价**：自动为所有待评价的教师提交满分评价，快速完成任务（支持本科和专科）。

## 环境要求

* uv
* Python 3.x
* 以及代码中导入的其他必要库。

## 使用说明

1. **克隆或下载项目**

   ```bash
   git clone https://github.com/Sen0E/CxArot.git
   cd CxArot
   ```
2. **安装依赖**

   ```bash
   uv sync
   ```
3. **配置信息**
   打开 `main.py`，找到配置区域，填入你的学号和密码。

   ```python
   # ...
   users = {"YourPhoneNumber": "YourPassword","YourPhoneNumber2": "YourPassword2"}
   # ...
   ```

   **安全提示**：直接在代码中存储明文密码存在风险，请确保该文件不会被泄露。
4. **运行脚本**

   ```bash
   python main.py
   ```

   脚本将开始执行，并输出评价任务的完成日志信息。
